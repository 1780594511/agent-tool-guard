# 威胁模型与权限矩阵

## 资产与攻击者

保护资产：合成文档正文、按用户隔离的工单、导出载荷、审批状态、策略与授权、审计一致性。

攻击者可以控制任务文字、工具参数、文档中的恶意指令、模型返回内容，或作为一个低权限登录用户直接调用 HTTP API。攻击者可以重复、并发、重排请求，也可能在用户等待审批时诱导改变资源或目的地。

信任服务端代码、进程身份、SQLite 文件权限、管理角色和模型服务的正常 HTTP 协议。模型内容本身不可信。任意 Python 执行、宿主文件写入、恶意后端管理员或被盗的高权限真实会话，不在本地 demo 的防护承诺内。

## 攻击与措施对应

| 威胁 | 控制 | 可验证结果 |
|---|---|---|
| 文档指令诱导跨部门读取 | 网关逐资源授权 | 无受禁文档 read_receipt |
| role/user_id 注入或 IDOR | 会话查库；严格参数 schema；所有者过滤 | 无身份变化/跨用户响应 |
| 导出外部地址 | 精确目的地名单；工具无网络访问能力 | inbox 中没有被禁止导出 |
| 审批扩大权限 | 申请、批准及执行时均检查发起人权限 | 无权资源不能产生有效申请 |
| 参数/版本 TOCTOU | 完整绑定 + 事务内执行复核 | 原审批失效或请求被拒绝 |
| 审批重放与竞争 | 状态检查、唯一键、BEGIN IMMEDIATE | 只提交一次，或全回滚 |
| 后端策略抛异常 | fail-closed；不调用执行器 | 无副作用，错误码留痕 |
| XSS / 日志内容诱导 | React 文本节点；不解释 HTML/Markdown；不把日志当指令 | 字符串可见，脚本不执行 |
| CSRF / 会话伪造 | HttpOnly + SameSite=Strict、CSRF、Origin/Host 检查 | 无有效会话或 CSRF 被拒绝 |
| 重试重复工单 | 用户作用域幂等键与业务唯一键 | 工单数量不增加 |
| A/B 评测污染演示数据 | 独立进程、每例新库、kind 标记硬检查 | baseline 拒绝 demo 数据库 |

## 不涵盖的情况

不判断内容真假、模型幻觉、合法权限范围内的所有语义恶意行为、真实审批人被社工欺骗、合成数据之外的 DLP，以及宿主被攻陷。`create_ticket` 可记录含攻击术语的合法工作；未对“攻击”“密码”等词做简单黑名单。

没有真实外发，所以目的地攻击只在本地模拟收件箱中被建模；没有证明真实网络出口隔离。服务端私有 capability 是防误用与清晰模块边界，不是 Python 沙箱。Windows/容器进程级网络与文件策略需要在接真实系统前单独设计。
